## 4. 使用示例查询

### 4.1 查询疾病信息
```cypher
// 查询某疾病的基本信息
MATCH (d:Disease {name: "感冒"})
RETURN d.name, d.desc, d.prevent, d.cause

// 查询某疾病的所有症状
MATCH (d:Disease {name: "感冒"})-[r:has_symptom]->(s:Symptom)
RETURN s.name

// 查询某疾病的推荐药物
MATCH (d:Disease {name: "感冒"})-[r:recommand_drug]->(dr:Drug)
RETURN dr.name
```

### 4.2 查询治疗方案
```cypher
// 查询某疾病的完整治疗方案
MATCH (d:Disease {name: "感冒"})
OPTIONAL MATCH (d)-[r1:common_drug]->(dr1:Drug)
OPTIONAL MATCH (d)-[r2:recommand_drug]->(dr2:Drug)
OPTIONAL MATCH (d)-[r3:cure_way]->(c:Cure)
RETURN d.name, dr1.name as common_drug, dr2.name as recommand_drug, c.name as cure_way
```

### 4.3 查询饮食建议
```cypher
// 查询某疾病的饮食建议
MATCH (d:Disease {name: "感冒"})
OPTIONAL MATCH (d)-[r1:do_eat]->(f1:Food)
OPTIONAL MATCH (d)-[r2:no_eat]->(f2:Food)
OPTIONAL MATCH (d)-[r3:recommand_eat]->(f3:Food)
RETURN d.name, f1.name as do_eat, f2.name as no_eat, f3.name as recommand_eat
```

### 4.4 查询检查项目
```cypher
// 查询某疾病需要做的检查
MATCH (d:Disease {name: "感冒"})-[r:need_check]->(c:Check)
RETURN c.name
```

### 4.5 查询并发症
```cypher
// 查询某疾病的并发症
MATCH (d:Disease {name: "感冒"})-[r:acompany_with]->(d2:Disease)
RETURN d2.name
```

### 4.6 查询科室信息
```cypher
// 查询某疾病所属科室
MATCH (d:Disease {name: "感冒"})-[r:belongs_to]->(dep:Department)
RETURN dep.name

// 查询某科室下的所有疾病
MATCH (dep:Department {name: "心内科"})<-[r:belongs_to]-(d:Disease)
RETURN d.name
```

### 4.7 查询药物生产商
```cypher
// 查询某药物的生产商
MATCH (p:Producer)-[r:drugs_of]->(dr:Drug {name: "阿莫西林"})
RETURN p.name
```

### 4.8 统计查询
```cypher
// 统计各科室的疾病数量
MATCH (dep:Department)<-[r:belongs_to]-(d:Disease)
RETURN dep.name, count(d) as disease_count
ORDER BY disease_count DESC

// 统计最常见的症状
MATCH (d:Disease)-[r:has_symptom]->(s:Symptom)
RETURN s.name, count(d) as disease_count
ORDER BY disease_count DESC
LIMIT 10
```

## 5. 数据库维护说明

### 5.1 数据备份
建议定期备份 Neo4j 数据库，可以使用以下方法：
1. Neo4j Aura 自动备份
2. 使用 `neo4j-admin dump` 命令导出数据
3. 使用 Cypher 脚本导出数据

### 5.2 数据更新
如需更新数据：
1. 准备新的数据文件
2. 运行部署脚本重新导入（会清空现有数据）
3. 或使用 Cypher MERGE 语句增量更新

### 5.3 性能优化
1. 为常用查询属性创建索引：
```cypher
CREATE INDEX disease_name IF NOT EXISTS FOR (d:Disease) ON (d.name)
CREATE INDEX drug_name IF NOT EXISTS FOR (d:Drug) ON (d.name)
CREATE INDEX symptom_name IF NOT EXISTS FOR (s:Symptom) ON (s.name)
```

2. 使用 EXPLAIN 或 PROFILE 分析查询性能

### 5.4 安全建议
1. 定期更换数据库密码
2. 限制数据库访问 IP
3. 使用加密连接 (neo4j+s://)
4. 不要在代码中硬编码密码
