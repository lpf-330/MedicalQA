# 依赖适配接口文档 v1

## 文档说明

本文档记录项目框架中所有外部依赖的适配接口说明。每个依赖在适配层适配后，都会在本文档中记录转接后对内部提供使用的接口详细说明，以方便项目框架内其他任何地方的使用。

---

## 一、依赖适配原则

### 1.1 为什么需要适配？

1. **解耦**：将外部依赖的具体实现与业务逻辑分离
2. **统一接口**：为不同类型的外部依赖提供统一的访问接口
3. **便于替换**：当需要更换外部依赖时，只需修改适配层实现
4. **简化调用**：上层模块无需关心外部依赖的具体使用方式

### 1.2 适配层位置

```
src/resource_manager/external_adapters/
├── base_adapter.py             # 基础适配器接口
├── neo4j/                      # Neo4j适配
├── vllm/                       # VLLM适配
├── langchain/                  # Langchain适配
└── milvus/                     # Milvus适配
```

### 1.3 适配流程

1. 在`external_adapters/`下创建依赖的适配包
2. 创建适配器接口（`{dependency}_adapter.py`）
3. 创建适配器实现类（`{dependency}_adapter_impl.py`）
4. 在本文档中记录适配后的内部接口说明

## 三、适配器使用规范

### 3.1 在资源管理层使用适配器

```python
# 示例：在VLLMModelResource中使用VLLMAdapter
class VLLMModelResource(Resource):
    def __init__(self, config: VLLMModelConfig):
        self._config = config
        self._adapter = VLLMAdapterImpl()  # 使用适配器
        self._last_used_time = time.time()
        self._is_active = False
    
    def activate(self):
        self._adapter.load_model(
            model_path=self._config.config_protocol["model_path"],
            tensor_parallel_size=self._config.config_protocol["tensor_parallel_size"]
        )
        self._is_active = True
        self._last_used_time = time.time()
    
    def deactivate(self):
        self._is_active = False
    
    def destroy(self):
        self._adapter.unload_model()
```

### 3.2 在编排层使用适配器

```python
# 示例：在ConsultModelService中使用VLLMAdapter（通过资源管理层）
class ConsultModelService(ModelBusinessService):
    def _init_Model(self):
        # 从资源管理层获取模型资源
        self._model_handle = GlobalResourceManager.acquire("vllm_model")
        self._model_client = self._model_handle.get_client()
    
    def call_model(self, messages: List[Dict]) -> str:
        # 使用模型客户端（内部使用适配器）
        prompt = self._format_messages(messages)
        result = self._model_client.generate(prompt)
        return result
```

## 四、适配器开发规范

### 4.1 适配器接口命名规范

- 接口名：`{Dependency}Adapter`
- 实现类名：`{Dependency}AdapterImpl`

### 4.2 适配器文件结构规范

```
external_adapters/{dependency}/
├── __init__.py
├── {dependency}_adapter.py      # 适配器接口
└── {dependency}_adapter_impl.py # 适配器实现类
```

### 4.3 适配器方法命名规范

- 连接类方法：`connect`, `disconnect`
- 数据操作方法：`insert`, `search`, `update`, `delete`
- 模型操作方法：`load_model`, `unload_model`, `generate`
- 工具创建方法：`create_{type}`

### 4.4 文档更新规范

每完成一个依赖的适配，必须：
1. 在本文档中添加该依赖的适配接口说明
2. 包含完整的接口定义和使用示例
