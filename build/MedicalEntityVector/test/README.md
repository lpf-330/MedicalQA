# 测试用例说明

## 1. 测试用例文件

### 1.1 test_queries.json
包含20个医疗健康查询测试用例，覆盖以下场景：
- 疾病症状查询
- 疾病用药查询
- 疾病病因查询
- 症状检查查询
- 饮食禁忌查询
- 症状诊断查询
- 药物适应症查询
- 疾病预防查询
- 疾病治疗查询
- 疾病传染性查询
- 易感人群查询
- 疾病恢复查询
- 科室查询
- 营养成分查询
- 症状调理查询
- 疾病生活指导查询
- 儿童健康查询
- 检查项目查询
- 疾病饮食查询
